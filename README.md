# Archideus

Archideus is a multiplayer city building game set in ancient Greece during the Classical Period (480–323 BC). For information about the game mechanics, story, design, and more, check out the [documentation written for obsidian](./docs/Archideus.md). The rest of this README will go through the technical details regarding development and installation of the game.

The game is build in the [Godot game engine](https://godotengine.org/) the [implementation can be found in the game folder](./game/).
